# Model 3D graffiti

Încarcă modelul original în acest director sub numele exact `graffiti-character-3d.glb`.

URL de încărcare: `https://github.com/ivanovroxana1988-arch/paul/upload/preview/interactive-3d/assets`

Aplicația din `index.html` folosește `./assets/graffiti-character-3d.glb` prin Three.js GLTFLoader.

Modelul este un GLB static. După încărcare, apare în scena 3D în locul avatarului demonstrativ, dar rigging-ul și animația realistă rămân separate.
